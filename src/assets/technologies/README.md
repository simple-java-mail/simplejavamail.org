# Technology marks

These local assets identify technologies used by the runnable Strategic Patterns. Keep the accompanying names readable, preserve each mark's proportions and colours, and link the names to their projects on the pattern pages.

The marks belong to their respective owners. Their presence describes the example's stack and does not imply endorsement of Simple Java Mail. A favicon is an image source, not a different licence or a blanket permission to use the mark.

See the source and usage references below before replacing an asset. Do not apply CSS colour filters or reconstruct logos.

## Usage references

This is independent open-source documentation identifying the software used by working examples. It makes no partnership, certification or endorsement claim. That context does not create a blanket exception to an owner's trademark rules.

- [Spring trademark guidance](https://spring.io/trademarks/) distinguishes names from logos and does not grant a general open-source or favicon exception. `spring.svg` is Spring's publicly served favicon, used here as an unchanged reference mark. Do not describe its availability as an unrestricted logo licence.
- [Apache Kafka trademark guidance](https://kafka.apache.org/community/trademark/) and [ASF guidance](https://www.apache.org/foundation/marks/faq/index.html) apply to the Kafka and Camel marks.
- [PostgreSQL trademark policy](https://www.postgresql.org/about/policies/trademarks/) covers PostgreSQL and Slonik.
- [Temporal brand resources](https://temporal.io/brand) and [Camunda brand resources](https://camunda.com/brand/) provide their respective artwork guidance.
- [RabbitMQ trademark guidelines](https://www.rabbitmq.com/trademark-guidelines) cover the RabbitMQ mark.
- [CNCF artwork terms](https://github.com/cncf/artwork/blob/master/LICENSE.md) and [Linux Foundation trademark guidelines](https://www.linuxfoundation.org/legal/trademark-usage) cover OpenTelemetry.
- [OpenJDK's Duke project](https://openjdk.org/projects/duke/) describes the mascot used to identify Java.
- [HashiCorp's design system](https://github.com/hashicorp/design-system) supplies the Terraform Flight icon under MPL-2.0. Its licence is retained alongside the icon as `LICENSE-terraform.txt`; the editable source remains `terraform.svg`.

Public attribution appears under Technology credits on the Strategic Patterns directory. Update it when adding a technology with additional attribution requirements.
